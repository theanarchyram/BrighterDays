Adds the Brighter Days shopkeeper game by LeverOne Studios to your site.

== Description ==

Brighter Days is a pixel-art shopkeeper game that runs in the browser. Haggle with customers, catch thieves, salvage scrap, forge masterworks, and run your shop from the Medieval Age to the Neon Age.

Shortcodes:

* [brighter_days] embeds the playable game. Options: ratio, height, max_width, fullscreen_link.
* [brighter_days_banner] shows the animated ad banner. Options: link, animated.

Settings are under Settings > Brighter Days.

The plugin updates itself from the releases on GitHub (theanarchyram/BrighterDays). Auto-updates are on by default and can be switched off in its settings.

== Installation ==

1. In WordPress, go to Plugins > Add New > Upload Plugin and choose the plugin zip.
2. Activate the plugin.
3. Create a page (for example "Play Brighter Days") and add [brighter_days].
4. Put [brighter_days_banner link="/play-brighter-days/"] on your homepage.
